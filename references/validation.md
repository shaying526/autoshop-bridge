## 可直接重放的离线测试

从本次加载的Skill目录取得`$skill`，`$out`设为用户选择的全新绝对目录，位于Skill目录之外。命令会**只在该新目录生成合成样例并修改它们**，不调用AutoShop、不编译、不读客户工程：

```powershell
python -B "$skill/scripts/check_bundle.py"
python -B "$skill/examples/offline_smoke.py" --output $out
```

项目A：新目录中的ST程序与HCP登记，正文注释同LF替换。项目B：另一目录、含空格/中文路径的ST函数FC与局部变量；另复制完整包到新位置并从无关cwd调用，验证不依赖开发路径。均经原CLI扫描、导出、读片段、补丁预检/应用、候选、原生写入、完整回读与恢复；同时验证原变量/不透明字节、其他文件、备份、旧补丁和外部冲突拒绝、包内文件未改。不把合成容器声称为AutoShop可打开或编译工程。

输出`results.json`记录逐步命令、退出码、状态、实测耗时及不变量。失败保留新目录中的实际工件，不删除或继续写入其他项目。Token字段为null，原因是本地CLI无宿主Token计量；不估算。
