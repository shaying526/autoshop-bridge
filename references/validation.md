## 可重放的合成工程

从加载的Skill位置取得$skill。$outLegacy和$outOffline为两个不同且尚不存在的绝对输出目录，在安装目录及原生工程目录外。脚本只生成并修改自己的合成样例，不连接AutoShop、不读客户工程、不编译。

```powershell
python -B "$skill/scripts/check_bundle.py"
python -B "$skill/examples/offline_smoke.py" --output $outLegacy
python -B "$skill/examples/offline_development_smoke.py" --output $outOffline
```

- 旧入口：A为ST同LF注释替换，B为另一目录的FC及局部变量，验证旧命令、唯一备份、回读、未知字节保护和恢复。
- 新offline：A/B均为一行零变量FB、ST、两个扁平结构和非空GVT，验证三个内部VAR BOOL/INT/DINT、两个结构INOUT、多行正文和两结构全局变量的export/check/build/apply/restore。检查plan/receipt外部摘要、未分配地址、旧记录、非目标及恢复字节。Windows用真实临时文件执行独占HCP守卫；其他平台明确skipped，不把模拟守卫当作通过。
- B包含不同目录、中文/空格和完整搬包，从无关cwd调用，检查原包及搬移包保持。合成容器不证明AutoShop可加载或编译。
- s11的offline冒烟另覆盖已有/空FC标量新增、旧记录/完整正文保持及完整恢复；仍不连接IDE或编译。

检查results.json、每条CLI退出码及case状态。失败/跳过时保留产物，不改其他工程。Token字段为null（本地CLI无宿主计量），不估计；耗时由脚本实测。
